# Prédiction-de-Sentiment-dans-les-Tweets-Financiers

L’objectif de ce projet est d’appliquer des techniques de Machine Learning et de traitement automatique du langage naturel (NLP) afin de prédire le sentiment exprimé dans des tweets liés à la finance. Plusieurs modèles de classification sont étudiés et comparés, notamment la régression logistique, K-Nearest Neighbors, Random Forest, les réseaux de neurones, BiLSTM avec embeddings et BERT.

Les modèles sont évalués dans le cadre d’une classification binaire (négatif vs non-négatif). BERT obtient les meilleures performances, avec une précision, un recall et un F1-score pondéré de 0,93. Une classification multi-classes (négatif, neutre, positif) est également réalisée à l’aide de TF-IDF et d’une régression logistique, avec un F1-score pondéré de 0,75.
